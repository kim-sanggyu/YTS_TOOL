# hometax-calc (국세청 모의계산 검증도구)

## 작업 원칙

- 이 도구를 손대면 **맵현황(맵정보 `mapping/{year}.ts` + 맵현황 화면)부터 갱신·확인하고 시작**한다. 맵현황이 시스템 이해·소통의 중심이자 단일원천이다.
- yts in 원천은 맵정보의 `inSource: { table, field, where, agg }` 로 **구조화 표현**한다(어느 테이블·어느 필드·어떤 조건·후처리는 뭔지). 새 항목을 손댈 때 그 항목 `inSource` 를 채운다(점진 — 일괄 아님).
- 가상컬럼형(`injectXxx`)은 **맵정보=계약 / 코드=소스가 이원**이다. 소스(`lib/runCompareForCalcNo.ts`)를 고치면 맵정보의 `inSource`·`note` 도 **함께 동기**한다(안 그러면 조용한 오염).

※ 4데이터(yts/nts × in/out) 취득 구조·단일원천 틀의 배경은 프로젝트 메모리 참조.
